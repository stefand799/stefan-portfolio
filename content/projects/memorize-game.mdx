## About the project

Developed a cross-platform memorizing pairing game using C# with MVVM architecture and Avalonia UI. The project features responsive, user-friendly design and demonstrates clean separation of concerns between the UI and business logic layers.

## Architecture

The project uses the **MVVM** (Model-View-ViewModel) pattern, keeping business logic completely decoupled from the UI. This made individual component testing straightforward and the codebase easy to navigate.

## What I learned

This project gave me hands-on experience with Avalonia UI — a powerful cross-platform .NET UI framework. I deepened my understanding of reactive programming principles and the MVVM pattern in a real project context.
