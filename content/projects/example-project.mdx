## About the project

Developed the backend for a retro-inspired multiplayer game using modern C++. Handled HTTP request routing with Crow and CPR, and implemented robust database management functions with SQLite ORM.

## What I built

- HTTP request routing with the Crow framework
- Database management with SQLite ORM
- User data handling and authentication
- Lobby system logic
- Server-side game mechanics

## What I learned

Working on this project deepened my understanding of C++ network programming, REST API design patterns, and the challenges of building real-time game backends. Managing concurrent connections and keeping state consistent across the server were the most interesting challenges.
